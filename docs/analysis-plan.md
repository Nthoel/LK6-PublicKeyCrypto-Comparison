## Algoritma

## Metrik
- Waktu pembangkitan kunci
- Waktu enkripsi
- Waktu dekripsi
- Ukuran kunci publik

- Ukuran ciphertext
- Keberhasilan dekripsi

## Hipotesis Awal
- Hybrid RSA-AES paling cocok untuk file besar
- ECIES unggul pada efisiensi ukuran kunci
- RSA lebih mudah dipahami namun kalah efisiensi dari ECC
- ElGamal cenderung lebih besar output-nya dibanding skema lain
